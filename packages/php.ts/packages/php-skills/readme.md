# @nyar/php-skills

Agent guides for the PHP language services package. Install the skill, then ask the
agent to parse files, inspect tokens, triage diagnostics, or tune throughput.

## Install

```bash
npx skills add @nyar/php-skills --skill php-language -y
```

## Scope

The `php-language` skill covers the `@nyar/php` CLI/API, native binding resolution,
the `php-harness` diagnostics loop, and the Boost `language.php` ownership boundary.
It does not teach PHP application development or replace the parser.
